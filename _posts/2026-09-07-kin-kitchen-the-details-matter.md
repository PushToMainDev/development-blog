## Sprint 1 Complete

With last week marking the completion of sprint one we look at all the planning that got us there.  More importantly this last week also marked the percetion of are we going to build the whole app in swift then start building in Kotlin or are we going to build side by side pushing to keep both code bases similar as we build.  I took the first step into making that a reality.

## Agentic Coding Implementation

With the advancements that have come out latley with Claude code I was given the opportunity to see how well this product could translate the code from a native iOS swift and swiftUI to the native android Kotlin.  Let me tell you now, It did not disappoint . .. That much!

I gave claude code the right to read my entire iOS folder then built a blank andriod project and told it to simply translate the project into an andriod project.  It first built out the design system and through many tests I was able to tweak with the correct prompts the look and feel of the UI.  Most of the comments were telling it to look at a specific screen and ensure that it matched that screen.  To my surprise this seems to be a viable option to keep both code bases on track in the easiest manner possible.
